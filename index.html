Use

Pipelines should pin a version, for example https://liberalilab.github.io/vocab/v0.0.1/<vocabulary>.json. Interactive tools may use https://liberalilab.github.io/vocab/latest/<vocabulary>.json. terms.json in each release maps every ID to its vocabulary.
